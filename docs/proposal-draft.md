## 0. 표지 · 목차  〔약 2장〕

- 제목 / 팀명 / 팀원 〔팀〕 / 제출일
- **선택 데이터셋명 명기**: 경북대학교병원 입원환자 활력징후 데이터 (필수 기재)
- 한 줄 요약: *"환자 자신의 기저선에서 벗어나는 순간을, 왜 위험한지와 함께 알리는 설명가능한 심정지 조기경보."*

## 1. 배경 및 필요성  `[시의성]`  〔약 4장〕

- **원내 심정지(IHCA)의 심각성**: 생존·퇴원율이 낮고 후유장애가 큼. 발생 수 시간 전부터
  활력징후가 서서히 악화되는 경우가 많아 **조기경보의 임상적 여지**가 크다.
- **조기경보점수(EWS)의 현실적 한계 = alarm fatigue**:
  - 기존 EWS(NEWS/MEWS)는 **병동 공통 고정 임계값** 기반 → 개인차 무시.
  - 심정지는 극단적 희귀사건 → **AUROC는 높아도 AUPRC가 낮아 오경보가 과다**.
  - 알람이 너무 잦으면 의료진이 무시(alarm fatigue) → **실제 도입·활용 저조**.
  - 병원 간 일반화도 약해 타 기관 이식이 어렵다.
- **간극 = 공략 지점**: "더 정확한 예측"이 아니라 **"믿고 쓸 수 있는(적은 오경보 + 근거 제시)
  경보"**가 임상 미충족 수요다. → 국민 환자안전 향상에 직접 기여.

## 2. 문제 정의 및 목표  〔약 2장〕

- **과제**: 시점별 활력징후(맥박·수축기/이완기혈압·체온·SpO₂·호흡수)로, 향후 단기간(예: 1시간)
  내 심정지 위험을 **조기에·적은 오경보로·근거와 함께** 경보.
- **목표 지표**: AUROC가 아니라 **AUPRC / 고정 특이도에서의 민감도 / 오경보율 / 조기경보
  확보시간(lead-time) / 단위시간당 알람 수**로 성공을 정의.

## 3. 기존 접근과 한계  〔약 2장〕

| 접근 | 한계 |
|---|---|
| NEWS/MEWS (규칙 기반) | 고정 임계값·개인차 무시·오경보 다수 |
| 딥러닝 EWS(LSTM 등) | 무거움·해석 어려움·폐쇄망/소표본 부적합·병원 간 일반화 약함 |
| 일반 ML 예측모델 | AUROC 위주 평가로 오경보 문제 은폐, "왜 위험한지" 설명 부재 |

→ **경량·설명가능·개인화·오경보 중심**이라는 빈자리를 겨냥.

## 4. 제안 아이디어  `[참신성]`  〔약 5장〕  ★핵심

**두 축의 차별화 + 데이터의 약점을 방법으로 전환.**

1. **개인화 기저선 이탈(Personalized baseline deviation)**
   - 병동 공통 임계값이 아니라 **각 환자의 초기 안정기를 개인 기저선**으로 삼아,
     그로부터의 이탈을 위험신호로 사용.
   - "환자가 곧 자신의 대조군" → **개인차로 인한 오경보를 줄이고 병원 간 전이성↑**.
2. **설명가능성(XAI) 내장**
   - 모든 경보에 대해 **왜 위험한지**(SHAP 기반 상위 기여 vital·추세)를 함께 제시 →
     임상 신뢰·수용성·간호 개입 우선순위 판단 지원.
3. **case-only 데이터의 역설을 정면 돌파**
   - 경북대 데이터는 **심정지 후 사망 환자만(대조군 없음)**. 이를 한계가 아니라
     **within-patient 설계(안정기=음성, 심정지 직전=양성)** 의 근거로 삼고,
     오경보 추정의 한계는 **외부 대조군(MIMIC-IV 등)으로 보완**한다는 방법론을 명시.

> **한 문장 차별점**: *"정확도 경쟁을 우회하고, 개인화·설명·오경보라는 임상 도입의 실제 장벽을 푼다."*

## 5. 데이터 활용 방안  `[실현성]`  〔약 3장〕

- **테이블·조인**: `KHTH_PINFO`(연령대·성별·입퇴원·심정지시각 `CARDT`·사망시각) +
  `KHTH_VITAL`(시점별 HR/SBP/DBP/BT/SPO2/RR), **`PATID`+`INDD`로 연결**.
- **라벨링**: `CARDT` 기준 정확한 심정지 시각으로 **within-patient** 양/음성 부여.
- **관찰창 확보**: 대회 제외기준(입원 24h 이내 심정지 제외)으로 **전 환자 ≥24h 활력징후** 보장.
- **정제**: 자유문자열 `VS_RSLT`의 센서 아티팩트·단위 이상 → 생리학적 범위 밖 값은 결측 처리
  (개발 중 MIMIC 실데이터에서 확인된 이슈를 사전 방어).
- **정적 변수**: 연령대·성별을 보조 피처로 활용(예후 보정·설명 강화).

## 6. 분석 방법론  `[실현성]`  〔약 4장〕

```
활력징후 시계열
  → 슬라이딩 윈도우(과거 N시간) 통계 피처
     (vital별 평균/표준편차/최소/최대/최근값/추세(slope)/변화량 + shock index)
  → ★ 개인 기저선 이탈 피처({vital}_last_dev, _mean_dev)
  → 라벨(within-patient): 향후 1시간 내 심정지 여부
  → cost-sensitive XGBoost  (비교군: NEWS 임상표준)
  → 평가: AUPRC·AUROC·민감도@95%특이도·오경보율·알람수·lead-time
  → 설명: SHAP 전역 + 경보별 상위 기여 요인
```

- **환자단위 분할**로 누수 방지, **train-median 결측 대치**로 정보 누수 차단.
- **불균형 처리**: `scale_pos_weight`, **AUPRC 기준 최적화**.
- **폐쇄망 적합 경량 스택**: `numpy·pandas·scikit-learn·xgboost·shap·matplotlib`만 사용
  (사전신고 목록 최소화, 안심존 오프라인 실행 보장).

## 7. 예비 검증 결과  `[실현성]`  〔약 3장〕 — *합성·MIMIC 개발 데이터 기준*

- **오경보 논지 실증**: XGBoost vs NEWS에서 **ROC-AUC는 거의 동일(~0.99)한데 AUPRC는 크게
  벌어짐**(개발 데이터에서 XGBoost 0.77~0.97 vs NEWS 0.42~0.61) → "ROC만 보면 안 보이는
  오경보 격차"를 그대로 재현.
- **동일 민감도 알람부담 비교(핵심 수치)**: 검출률(민감도)을 고정하고 비교하면 —
  **90% 민감도에서 XGBoost 오경보율 0.45·알람 2.0/100 vs NEWS 0.61·2.9/100**, 96~99% 고민감도
  구간에서 **NEWS는 알람이 16~36/100으로 폭증**하는데 XGBoost는 ~3/100 유지 → *"같은 검출,
  훨씬 적은 오경보"* 를 정량 입증.
- **개인화 피처 효과**: 개인 기저선 이탈 피처 추가 시 **AUPRC 0.76 → 0.84**(합성) 상승.
- **설명가능성**: SHAP 상위 기여 = **호흡수·SpO₂·맥박의 추세(slope)** → 악화 추세 포착이
  조기경보의 본질임을 확인.
- **실데이터 파이프라인 검증**: 실제 **MIMIC-IV**에서 로딩→정제→윈도우→모델까지 end-to-end
  동작 확인(코드·테스트 공개). 〔본선〕 경북대 데이터로 동일 파이프라인 적용 예정.

- **심정지 표현형 발견(보조 참신성)**: 심정지 직전 궤적을 비지도 군집화하면 **호흡성형·순환성형·
  혼합형** 등 서로 다른 악화 아형이 드러남(개발 데이터에서 확인). 표현형별 맞춤 경보로 확장 가능.

> 그림 자리: (i) PR-curve 비교, (ii) 악화 궤적 + 경보시점, (iii) SHAP 요약, (iv) lead-time 분포,
> (v) 심정지 표현형 히트맵, (vi) 동일 민감도 알람부담 곡선.

## 8. 기대효과 및 파급성  `[파급성]`  〔약 3장〕

- **환자안전**: 오경보를 줄여 실제 병동에서 쓰이는 EWS → 심정지 조기대응·생존율 개선 기여.
- **의료 현장**: 설명가능 경보로 간호 인력 배치·중환자 조기 스크리닝 프로토콜 고도화.
- **확장성**: 개인화 기반이라 **타 병원 이식 용이**. 활력징후만으로 동작 → 도입 장벽 낮음.
- **발전 로드맵**: (인턴 트랙) **ECG·RR interval·HRV** 확장으로 정밀도 향상, 다기관 외부검증.

## 9. 추진 계획 · 안심존 활용  〔약 1.5장〕

- 일정: 예선(설계·예비검증) → 본선(안심존 실데이터 분석·시각화 보고서·발표).
- **안심존 방문 계획**: 예선 기간 1회 이상 방문(가점) + 본선 다회 방문. 결과물 반출은
  마감 여유 두고 조기 신청(심의 1~2주 감안).
- **폐쇄망 대응**: 사전신고 패키지 확정, 외부 다운로드 0 의존.

## 10. 결론  〔약 0.5장〕

정확도 경쟁이 아니라 **오경보 저감 + 설명가능성 + 개인화**로 임상 도입의 실제 장벽을 푸는,
가볍고 이식 가능한 심정지 조기경보를 제안한다. 경북대 활력징후 데이터의 case-only 구조는
within-patient 설계로 자연스럽게 활용되며, 사전 검증된 파이프라인으로 실현성을 담보한다.
