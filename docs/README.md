# 문서 지도

이 폴더의 문서들이 각각 무엇이고, **언제 봐야 하는지** 정리했습니다.

---

## 목적별로 찾기

### "지금 프로젝트가 어떤 상태지?"
→ **[`STATUS.md`](STATUS.md)**

대회 개요, 확정된 주제, 데이터 현황, 완료된 작업과 남은 일이 한 장에 정리돼 있습니다.
**오랜만에 프로젝트로 돌아왔다면 여기부터** 보세요.

### "대회에서 어떻게 이길 건데?"
→ **[`competition-strategy.md`](competition-strategy.md)**

심사 배점(시의성 20 · 실현성 30 · 참신성 30 · 파급성 20)에 맞춰 우리 논지를 어떻게 배치할지,
왜 이 주제·이 데이터를 골랐는지가 담겨 있습니다.

### "제안서 뭐라고 쓰지?"
→ **[`proposal-draft.md`](proposal-draft.md)**

예선 제출용 30장 제안서의 절별 골격과 본문 초안입니다. 맨 아래 **제출 전 형식 체크리스트**
(PDF·30장·마감시각 등 실격 방지 항목)를 꼭 확인하세요.

> ⚠️ 현재 문서의 예비 수치는 **전부 합성 데이터 기반 시연**입니다. 실제 환자 성능이 아니며,
> 실데이터 확보 순서대로 교체할 예정입니다.

### "본선 발표에서 뭐라고 답하지?"
→ **[`differentiation.md`](differentiation.md)**

경쟁 팀들이 취할 법한 접근과 그 약점, 우리 차별점 5가지, 그리고 심사위원 예상 질문에 대한
답변이 정리돼 있습니다. 본선 발표(70%) 대비용입니다.

### "서버에서 어떻게 돌리지?"
→ **[`server-runbook.md`](server-runbook.md)**

회사 GPU 서버(RTX A6000 ×2) 접속부터 conda 환경 구축, VS Code 원격 접속, 실행까지의 절차입니다.
**환경 구축에서 막히면 여기를 보세요.**

## 읽는 순서 (처음이라면)

```
1. STATUS.md                 지금 상황 파악
        ↓
2. ../README.md              프로젝트 구조와 지표 읽는 법
        ↓
3. competition-strategy.md   왜 이 주제인가
        ↓
4. proposal-draft.md         무엇을 제출하는가
        ↓
5. differentiation.md        어떻게 방어하는가
```

`server-runbook.md`는 필요할 때만 참고하면 됩니다.
